# Channel Research Reference Inventory

This document separates the three evidence layers used for future Shorts research:

1. the research brief supplied outside the repository;
2. the behavior implemented by this repository;
3. the channel Analytics export supplied with the project context.

The research brief is an instruction set, not evidence. Claims from it must be checked against primary sources or the channel data before they are used in a final report.

## Important implementation findings

- `NARRATION_ENGINE=kokoro` remains the default. Chatterbox is only active when it is explicitly selected in `.env`.
- The Chatterbox service discovers multiple reference files but synthesizes from the first one. The repository currently contains three WAV samples, so their presence does not mean all three are mixed into every voice generation.
- Kokoro already applies beat-level timing: hooks and escalations are faster, payoffs receive a longer pause, and each run has a small random speed variation. The existing humanization document therefore describes a partly implemented idea, not a completely missing feature.
- Generic fact Shorts are generated by Ollama without a general fact-verification step. World Cup content is the exception because it reads the configured ESPN scoreboard endpoint. The README lists fact verification as a future improvement.
- The prompt forbids generic `3 Facts About ...` titles, while the Analytics export still contains many such titles. This should be treated as a lineage or enforcement issue until the generated run JSON is inspected.

## Analytics baseline supplied with the project context

The export contains 502 rows: 474 Shorts, 27 long-form videos, and one total row. For Shorts:

- median `Weergaven`: 851;
- maximum `Weergaven`: 2,038;
- median `Gemiddeld percentage bekeken`: 58.81%;
- median `Bleef kijken`: 32.56%;
- median `Abonnees`: 0;
- no 100K+ or 1M+ Shorts are present in this export.

Observed patterns, not causal conclusions:

- `3 Facts` appears in 78 of 474 Short titles (16.5%);
- titles containing `secret`, `weird truth`, or similar language appear frequently, but this does not establish that the wording caused more views;
- median viewed percentage declines across the available duration bands: approximately 69% for 1–20 seconds, 62% for 21–25 seconds, 59% for 26–30 seconds, and 52% for 31–35 seconds;
- some videos exceed 100% average percentage viewed. This is compatible with rewatches or loops, but must be validated against the original YouTube export before being used as evidence;
- the export has no script text, first-frame data, cut count, shares, comments, engaged views, or complete viewed-versus-swiped data.

The Analytics videos run through 25 August 2026. The Chatterbox branch commit is dated 8 September 2026. Therefore this export cannot measure the causal effect of the Chatterbox change.

## Measurement plan for the next cohort

For every new Short, preserve the run metadata together with the Analytics row. Add these labels before comparing results:

- topic and topic bucket;
- title pattern and hook type;
- narration word count and final duration;
- number of beats and beat types;
- voice engine, voice/model, and reference-clip identifier;
- visual-query specificity and number of visual changes;
- whether the content is generic Ollama content or explicitly grounded content;
- publication date and scheduled time.

Useful derived metrics:

```text
subscriber conversion per 1,000 = subscribers gained / views × 1,000
like rate                    = likes / views × 100
comment rate                 = comments / views × 100
share rate                   = shares / views × 100
viewed-to-swipe ratio        = viewed / swiped away
retention gap                = average percentage viewed − expected percentage from duration
```

Compare cohorts rather than isolated videos. In particular, use a post-branch cohort for Chatterbox versus a pre-branch Kokoro cohort, while keeping topic mix, duration range, upload schedule and title strategy visible as confounders.
